## 👋 About

I'm a mobile app developer who likes owning an app **from the first screen to the final release**: architecture, API and real-time integration, Play Store and App Store submissions, and the maintenance after launch.

I started with native Android in Java, moved to Kotlin, and added React Native so one codebase can ship to both stores. Knowing both sides means I can pick the right tool: native when an app depends on the device, React Native when speed and reach matter more.

- 🏢 **Now:** Mobile Application Developer at **AlgoSoft Apps Technologies**, Noida
- 🚖 **Building:** **ALO** (ride-hailing), **TradeGrid**, **Reachly** and a **Hospital Management** suite
